# FerveC Gastronomia

Projeto web estático em HTML, CSS e JavaScript, sem etapa de compilação.

## Executar localmente

Na pasta do projeto, inicie um servidor HTTP:

```sh
python3 -m http.server 8080
```

Abra `http://localhost:8080` no navegador. Também pode publicar os arquivos em qualquer hospedagem estática que sirva `index.html` na raiz.

O progresso de aulas e atividades fica salvo no `localStorage` deste navegador. O projeto não possui autenticação, checkout, matrícula paga, sincronização entre dispositivos ou emissão oficial de certificados conectados. Veja [CONFIGURACAO.md](CONFIGURACAO.md) para os detalhes funcionais.
